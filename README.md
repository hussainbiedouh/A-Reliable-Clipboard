# A-Reliable-Clipboard 📋

A robust, cross-platform clipboard manager built with Python.

## Features (Planned)
- Real-time clipboard monitoring
- History persistence
- Searchable history
- CLI and GUI interfaces
- Encryption support

## Installation

```bash
git clone https://github.com/hussainbiedouh/A-Reliable-Clipboard.git
cd A-Reliable-Clipboard
pip install -r requirements.txt
```
